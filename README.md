# 随手记小程序 PRD 导出文档

随手记小程序产品需求文档的原型 / PRD 静态导出包（Axure 导出格式）。本仓库仅做版本管理，不包含 PRD 源文件。

## 快速开始

```bash
# 方式一：直接双击 index.html（多数场景可用）

# 方式二：本地起 HTTP 服务后访问，避免 file:// 协议下的资源/跨域限制
cd "随手记小程序prd导出文档"
python -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

- `index.html` 与 `start.html` 内容一致，均为入口页面。
- `start_with_pages.html` 进入「页面列表」视图；`start_c_1.html` 为带 hash 参数的跳转入口。
- 单个需求文档也可直接打开对应 HTML，例如 `小程序预算中心-页面需求说明.html`。

## 目录结构

| 路径 | 作用 |
| --- | --- |
| `index.html` / `start.html` | 入口页面（原型播放器外壳，读取 `data/document.js` 渲染） |
| `data/document.js` | 原型结构、页面树与文案数据，体积最大的核心数据文件 |
| `data/styles.css` | 播放器与原型容器的全局样式 |
| `*.html`（根目录） | 各需求单页文档，文件名即需求名，多数带版本号，如 `（v1_5_1）` |
| `files/<需求名>/` | 各单页文档的独立资源（CSS、脚本、页面片段） |
| `images/` | 原型中的截图与图片资源，按页面 / 模块分目录 |
| `plugins/` | 原型播放器插件：`sitemap`（站点地图）、`page_notes`（页面说明）、`recordplay`（操作录制回放）、`debug` |
| `resources/` | 播放器运行时资源（JS、CSS、图标、字体、浏览器检测页） |

## 维护约定

1. **导出包整体替换**：PRD 更新时由源文件重新导出，覆盖此目录内容后提交一次完整变更，不做逐文件手工编辑。
2. **命名沿用源文件**：文件名即需求名 + 版本号，不在仓库内重命名，便于与 PRD 源文件一一对应。
3. **单次提交粒度**：一次导出 = 一次提交，提交信息格式 `导出：<导出日期> <变更概述>`。
4. **不提交本地垃圾文件**：系统临时文件、编辑器配置已在 `.gitignore` 中排除；`images/` 等二进制资源由 `.gitattributes` 标记，禁止换行转换。
5. **体积控制**：当前约 67 MB / 2700+ 文件，以图片为主。若后续显著增长，优先压缩图片，而不是删除历史。

## 状态说明

导出内容中的「草稿」「备选方案」「参考」「版本待定」等前缀表示该需求尚未定稿，需求状态以 PRD 源文件为准。
